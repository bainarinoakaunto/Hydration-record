# 💧 WaterLog

毎日の水分補給を記録・管理できるWebアプリです。

飲んだ量や飲み物を記録すると、今日の合計量・達成率・残りの量・次に飲む時間・週間・月間の記録などを確認できます。

---

## ✨ 主な機能

- 💧 水分補給の記録
- 🥤 飲み物の種類を記録
- 🕐 時刻を自動記録
- 🎯 1日の目標量を設定
- 📊 今日の合計量を自動計算
- 📈 目標達成率を表示
- 🧮 目標までの残り量を自動計算
- ⏰ 次に飲む時間を表示
- 🥤 次に飲む量を自動計算
- 🍵 飲み物別の集計
- 📅 週間レポート
- 📈 月間レポート
- ⚡ クイック記録
- 🍔 ハンバーガーメニュー
- ⚙️ 設定変更
- 💾 ブラウザへのデータ保存
- 📱 PC・スマートフォン対応
- 🌐 Webブラウザだけで利用可能

---

# 🌟 初回起動

初めてWaterLogを開くと、説明スライドが表示されます。

## 📖 説明スライド

### 1. 💧 WaterLogへようこそ
WaterLogの基本的な使い方を紹介します。

### 2. 🥤 飲んだものを記録
水・お茶・牛乳・スポーツドリンクなど、飲んだものを記録できます。

### 3. 📊 自動で集計
今日飲んだ量や目標達成率などを自動で計算します。

### 4. 🕐 次に飲む時間・量
最後に飲んだ時刻をもとに、次に飲む時間を表示します。
また、今日の記録をもとに次に飲む量の目安も表示します。

### 5. 📅 週間・月間レポート
過去の水分補給記録を、週間・月間単位で確認できます。

### 6. ⚙️ 初期設定
WaterLogを使い始める前に、基本設定を行います。

---

# ⚙️ 初期設定

初回起動時に以下を設定します。

- 🎯 1日の目標量
- ⏰ 次に飲むまでの時間
- 🥤 よく飲むもの

設定が完了するとWaterLogを利用できます。

一度設定すると、次回からは説明スライドをスキップして直接アプリを利用できます。

設定は後から変更できます。

---

# 🏠 ホーム

ホーム画面では、今日の水分補給状況をまとめて確認できます。

表示される情報：

- 💧 今日飲んだ量
- 🎯 1日の目標量
- 📈 目標達成率
- 🧮 目標までの残り量
- ⏰ 次に飲む時間
- 🥤 次に飲む量

---

# 💧 水分補給を記録

「水分補給を記録」から、飲んだ水分を登録できます。

## 記録できる情報

- 飲んだ量
- 飲んだもの
- 飲んだ時刻

時刻は現在時刻から自動的に記録されます。

---

# 🥤 飲み物

以下の飲み物を記録できます。

- 💧 水
- 🍵 お茶
- 🥛 牛乳
- 🥤 スポーツドリンク
- 🧃 その他

飲み物別の合計量も確認できます。

---

# ⚡ クイック記録

ホーム画面から、よく使う量をすばやく記録できます。

- 100mL
- 150mL
- 200mL
- 300mL

クイック記録では、設定した「よく飲むもの」を使用して記録します。

---

# ⏰ 次に飲む時間

最後に水分補給を記録した時刻と、設定した間隔をもとに次の時間を計算します。

例：

```text
最後の記録
14:00

↓

設定した間隔
60分

↓

次に飲む時間
15:00
```

まだ水分補給を記録していない場合は、次に飲む時間は表示されません。

---

# 🥤 次に飲む量

今日の目標量と現在までの記録から、残りの水分量を計算します。

そのデータをもとに、次に飲む量の目安を表示します。

例：

```text
1日の目標
1500mL

今日の記録
900mL

↓

残り
600mL
```

---

# 📊 今日の統計

今日の水分補給状況を詳しく確認できます。

表示項目：

- 💧 合計量
- 📝 記録回数
- 📐 1回あたりの平均量
- 🎯 目標までの残り量

---

# 📅 週間レポート

過去7日間の水分補給量をグラフで確認できます。

日ごとの記録を比較しながら、1週間の水分補給状況を振り返ることができます。

---

# 📈 月間レポート

現在の月の水分補給状況を確認できます。

表示項目：

- 📊 月間合計
- 📐 1日平均
- 🎯 目標達成日数

---

# 🍵 飲み物別集計

飲み物ごとの水分量を集計します。

例：

```text
💧 水                  1200mL
🍵 お茶                 600mL
🥛 牛乳                 200mL
🥤 スポーツドリンク      300mL
```

---

# 🍔 ハンバーガーメニュー

画面右上のハンバーガーメニューから各ページへ移動できます。

```text
🏠 ホーム
💧 水分補給を記録
📊 今日の統計
📅 週間レポート
📈 月間レポート
⚙️ 設定
```

スマートフォンでも操作しやすいように設計されています。

---

# ⚙️ 設定

設定画面からWaterLogの基本設定を変更できます。

変更できる項目：

- 🎯 1日の目標量
- ⏰ 次に飲むまでの時間

また、初期設定をやり直すこともできます。

初期設定をやり直しても、これまでの記録データは削除されません。

---

# 💾 データ保存

WaterLogでは、ブラウザの`localStorage`を使用してデータを保存します。

記録した水分補給データや設定は、基本的に利用しているブラウザ内に保存されます。

外部サーバーへ記録データを送信する機能はありません。

---

# 🔒 プライバシー

WaterLogでは、水分補給の記録に名前・住所・電話番号などの個人情報を入力する必要はありません。

記録データは基本的に利用しているブラウザ内に保存されます。

---

# 📱 対応環境

PC・スマートフォンのWebブラウザで利用できます。

レスポンシブデザインに対応しているため、画面サイズに合わせてレイアウトが変化します。

# ⚠️ 注意事項

## 💧 水分量について

WaterLogに表示される「1日の目標量」や「次に飲む量」は、あくまで**記録・管理のための目安**です。

必要な水分量には個人差があり、年齢、活動量、運動量、気温などによって異なります。

表示された数値を無理に達成する必要はありません。

## 🥤 無理な水分補給について

短時間に大量の水分を摂取するなど、無理な水分補給は避けてください。

自分の体調や状況に合わせて利用してください。

体調に異変を感じた場合は、アプリの表示よりも**体調を優先してください**。

## 🏥 医療目的ではありません

WaterLogは、水分補給の記録・管理を目的としたWebアプリです。

以下を目的としたものではありません。

- 医療行為
- 病気の診断
- 治療
- 医療上の判断
- 専門的な健康指導

健康や体調について不安がある場合は、保護者や医療専門家などに相談してください。

## 📊 自動計算について

WaterLogでは、記録されたデータをもとに以下の情報を自動計算します。

- 今日の合計量
- 目標達成率
- 残りの量
- 次に飲む時間
- 次に飲む量
- 週間・月間の集計

これらはアプリ上の計算結果であり、**医学的な判断や推奨を示すものではありません**。

## 💾 データ保存について

以下の場合などには、保存されたデータが失われる可能性があります。

- ブラウザの保存データを削除した場合
- ブラウザの設定を変更した場合
- 端末を変更した場合
- ブラウザ側の仕様によってデータが削除された場合

重要な記録については、必要に応じて各自で管理してください。

## 🌐 Webアプリについて

ブラウザや端末の種類・バージョンによって、表示や動作が異なる場合があります。

ブラウザのアップデートや仕様変更などにより、予告なく一部機能が正常に動作しなくなる場合があります。
